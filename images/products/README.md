# Фотографии товара

Сюда кладутся снимки из объявлений Авито — по одному на позицию.

## Как подключить

1. Положить файл: `public/images/products/<slug>.jpg`, где `<slug>` — поле `slug`
   товара из `src/data/catalog.json`.
   Пример: `reshetka-radiatora-bmw-g06-50d.jpg`.
2. В `src/data/catalog.json` у этого товара заполнить поле `image`:

```json
"image": "/images/products/reshetka-radiatora-bmw-g06-50d.jpg",
"imageAlt": "Решётка радиатора BMW G06 50d, вид спереди"
```

Всё. Карточка сама заменит рисованный силуэт на фотографию. Пока поле пустое или
отсутствует — остаётся заглушка, вёрстка не ломается.

## Можно и без скачивания

Вместо локального файла в `image` разрешён прямой адрес на CDN Авито:

```json
"image": "https://20.img.avito.st/image/1/..."
```

Домен `*.avito.st` уже разрешён в `next.config.ts`. Но локальные файлы надёжнее:
адреса на CDN меняются при перезаливке объявления, а само объявление однажды
закроется.

## Требования к файлам

- Пропорции кадра — **4:3**, карточка обрезает по `object-cover`.
- Ширина от 800px: на сетке в 4 колонки карточка занимает ~300px, но на телефоне
  разворачивается почти во всю ширину экрана.
- Формат JPG или WebP. Оптимизацией и раздачей в AVIF занимается Next.js.
- Главный кадр объявления, а не фото упаковки: в сетке видно только его.
